### 3. Теоретическая справка

#### 3.1. Что такое MPI?

**MPI (Message Passing Interface)** — это стандарт для организации параллельных вычислений в системах с распределенной памятью. В таких системах каждый процессор имеет свою локальную память, и для обмена данными между процессами используется передача сообщений.

#### 3.2. Основные понятия

| Термин | Описание |
|--------|----------|
| **Ранг (rank)** | Уникальный номер процесса в коммуникаторе |
| **Коммуникатор** | Группа процессов, участвующих в вычислениях |
| **Операции точка-точка** | `Send` и `Recv` — передача данных между двумя процессами |
| **Коллективные операции** | `Bcast`, `Scatterv`, `Gatherv` — взаимодействие всех процессов |

#### 3.3. Постановка задачи

Умножить матрицу `A` размерности `M × N` на вектор `x` длины `N`:

**Математически:** `b = A * x`, где `b[j] = Σᵢ A[j][i] * x[i]` для `j = 0, ..., M-1`

#### 3.4. Параллельный алгоритм

1. **Декомпозиция данных:** Матрица `A` разбивается на горизонтальные полосы (блоки строк). Каждый процесс получает свой блок `A_part` размером `local_M × N`.

2. **Распределение данных:** Процесс с рангом 0 (Master) считывает исходные данные и распределяет блоки матрицы `A` и весь вектор `x` между всеми процессами.

3. **Локальные вычисления:** Каждый процесс независимо вычисляет часть результирующего вектора `b_part = A_part * x`.

4. **Сбор результатов:** Процессы отправляют свои части `b_part` процессу 0, который собирает из них итоговый вектор `b`.

#### 3.5. Схема работы

```
Процесс 0 (Master)          Процесс 1          Процесс 2
    │                           │                  │
    ├─ Чтение A, x             │                  │
    │                           │                  │
    ├─ Scatterv(A) ────────────┼──────────────────┤
    │       A_part[0]          │    A_part[1]     │   A_part[2]
    │                           │                  │
    ├─ Bcast(x) ──────────────┼──────────────────┤
    │                           │                  │
    ├─ b_part[0] = A_part[0]*x │  b_part[1] = ... │  b_part[2] = ...
    │                           │                  │
    ├─ Gatherv(b) ◄────────────┼──────────────────┤
    │                           │                  │
    └─ Запись результата       │                  │
```

**Подсказка:** Используйте лекционный материал (стр. 5-6) для реализации.

**Пример кода:**
```python
def sequential_mat_vec_mult(A, x):
    """Последовательное умножение матрицы на вектор"""
    M, N = A.shape
    b = np.empty(M)
    for j in range(M):
        b[j] = 0
        for i in range(N):
            b[j] += A[j, i] * x[i]
    return b
```

**Подсказка:** Используйте лекционный материал (стр. 13-17) для реализации.

**Важно:**
- Обработать случай, когда `M` не делится нацело на число процессов
- Использовать `rcounts` и `displs` для произвольного разбиения

**Реализация `auxiliary_arrays_determination`:**
```python
def auxiliary_arrays_determination(M, numprocs):
    """Расчет rcounts и displs для разбиения данных"""
    ave, res = divmod(M, numprocs)
    rcounts = np.empty(numprocs, dtype=np.int32)
    displs = np.empty(numprocs, dtype=np.int32)
    displs[0] = 0
    for k in range(numprocs):
        rcounts[k] = ave + 1 if k < res else ave
        if k > 0:
            displs[k] = displs[k-1] + rcounts[k-1]
    return rcounts, displs
```

**Пример:** Для `M=7` и `numprocs=4`:
- `rcounts = [2, 2, 2, 1]`
- `displs = [0, 2, 4, 6]`

**Проверка:**
```bash
mpirun -np 4 python src/parallel_scatterv.py
```

**Ожидаемый результат:** Файл `Results_parallel.dat` с результатом умножения, совпадающий с последовательной версией.

### 11. Часто задаваемые вопросы

#### 11.1. Установка MPI

**Вопрос:** Как установить MPI на Windows?

**Ответ:**
1. Установите WSL2 (Windows Subsystem for Linux)
2. В WSL2 установите OpenMPI:
   ```bash
   sudo apt update
   sudo apt install openmpi-bin libopenmpi-dev
   ```

#### 11.2. Ошибка импорта mpi4py

**Вопрос:** `ModuleNotFoundError: No module named 'mpi4py'`

**Ответ:**
```bash
pip install mpi4py
```

#### 11.3. Дедлок в программе

**Вопрос:** Программа зависает при выполнении Send/Recv

**Ответ:**
- Проверьте, что для каждого `Send` есть соответствующий `Recv`
- Убедитесь, что порядок вызовов правильный
- Используйте `MPI.Status` для отладки

#### 11.4. Неправильный результат

**Вопрос:** Результат параллельной программы не совпадает с последовательной

**Ответ:**
- Проверьте правильность индексов при сборке результата
- Убедитесь, что `displs` рассчитаны корректно
- Проверьте, что вектор `x` получен на всех процессах

#### 11.5. Ошибка при M % numprocs != 0

**Вопрос:** Программа падает, если M не делится на numprocs

**Ответ:**
- Реализуйте функцию `auxiliary_arrays_determination()`
- Используйте `Scatterv` вместо `Scatter`
- Используйте `Gatherv` вместо `Gather`
